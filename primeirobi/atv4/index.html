Primeira atividade de Desenvolvimento Web

25 de Fevereiro de 2026

Este post apresenta as principais tags utilizadas em HTML.

Serve como introdução para iniciantes no desenvolvimento web.

Introdução ao CSS Grid

10 de Março de 2026

O CSS Grid permite criar layouts modernos com linhas e colunas.

Ele é ideal para estruturar páginas de forma organizada e responsiva.

Flexbox na prática

15 de Março de 2026

O Flexbox facilita o alinhamento de elementos em uma única direção.

É muito utilizado em menus, botões e componentes responsivos.

Responsividade com Media Queries

20 de Março de 2026

Media Queries permitem adaptar o layout para diferentes tamanhos de tela.

São essenciais para garantir boa experiência em celulares e tablets.
